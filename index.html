Supervised Learning

1. Linear Regression

การถดถอยเชิงเส้น ค้นหาเส้นตรง y = mx + c ที่ลดค่า Loss (MSE) ระหว่างจุดข้อมูลกับเส้นทำนาย

2. Logistic Regression

การจำแนกประเภทข้อมูลไบนารี โดยใช้ฟังก์ชัน Sigmoid แปลงค่าเป็นความน่าจะเป็น (0 ถึง 1)

3. k-Nearest Neighbors (kNN)

ค้นหาเพื่อนบ้านที่ใกล้ที่สุด k จุด และทำนายคลาสตามเสียงข้างมาก (Majority Voting)

4. Decision Tree

แบ่งโหนดตามเงื่อนไข (Feature Split) เพื่อลดค่า Entropy / Gini Impurity ให้ได้มากที่สุด

5. Random Forest

การรวมโมเดลต้นไม้หลายต้น (Ensemble Learning) โดยใช้วิธี Bagging เพื่อลด Variance

6. Support Vector Machine (SVM)

สร้าง Hyperplane ตัดแบ่งคลาสข้อมูลโดยให้ระยะขอบ (Margin) กว้างที่สุดเท่าที่เป็นไปได้

8. Multi-Layer Perceptron (MLP)

โครงข่ายประสาทเทียมหลายชั้น ปรับค่าน้ำหนัก (Weights) ผ่านอัลกอริทึม Backpropagation

13. XGBoost (Extreme Gradient Boosting)

สร้างต้นไม้ตัดสินใจอย่างต่อเนื่องโดยใช้ Gradient Boosting เพื่อแก้ข้อผิดพลาด (Residuals)

14. Stacking Model

นำผลทำนายจากหลากหลาย Base Models ป้อนเข้าสู่ Meta-Model เพื่อการทำนายขั้นสุดท้าย

Unsupervised Learning

7. K-Means Clustering

จัดกลุ่มข้อมูลโดยค้นหาจุดศูนย์กลาง K จุด และคำนวณปรับจุดศูนย์กลางด้วยค่าเฉลี่ยซ้ำๆ

Deep Learning Architecture

9. CNN (Convolutional Network)

การสกัดคุณลักษณะ (Features) จากภาพด้วย Filter Kernel และคำนวณ Feature Map

10. LSTM (Long Short-Term Memory)

โครงข่าย RNN แบบมี Forget Gate, Input Gate และ Output Gate เพื่อจดจำบริบทระยะยาว

11. Transformer (Self-Attention)

กลไก Multi-Head Self-Attention คำนวณความสัมพันธ์ของทุกคำในประโยคโดยตรงแบบ Parallel

Reinforcement Learning

12. Reinforcement Learning (Q-Learning)

Agent เรียนรู้จากการลองผิดลองถูกเพื่อสะสมรางวัล (Reward) สูงสุดด้วย Q-Table
